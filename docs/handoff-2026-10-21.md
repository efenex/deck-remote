## Gotchas
- Follower design: cap 8, 60 s idle stop, three fast exits → 2 min polling fallback, `resync_required` reopens, `--since` poll skipped while healthy (2 min safety poll). "Start/stop with the sheet" is approximated by the idle timeout.
- Chain: `before_cursor` is opaque or "" (chain start); an older page can end with a boundary already seen; uuid-less `other` rows share ids (`line::<hash>`). `!` lines are `kind:bash`, command in `detail`, output arrives as an update (`body`, `is_error`).
- Tests: `testServer` (`codex_test.go`) must keep `recall.follow=false`, `hub.tap=nil`, `tmux.interval=0`. Never start tmux on the default socket in tests; use `-L`.
- `make test` output must be read: a FAIL once printed while my command chain still committed.
- No `sed -i` in the sandbox; edit with Edit/python. macOS has no `timeout`.
